# Quick handoff

This is a ready-to-run frontend prototype for the TIS assignment.

1. Open this folder in VS Code.
2. Open terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. For submission, push to GitHub and deploy to Vercel.

Important: the visual prototype uses remote Unsplash images. If the evaluator expects TIS-owned images, replace the image URLs in `src/data/content.ts` and `src/sections/Hero.tsx` with approved assets from the official TIS site before submitting.
